# Contract: 保存账号个性化偏好

## 输入

- `city`: 2-40 个可见字符的中国城市名称。
- `clothingPreference`: `male | female | unrestricted`。

## 服务端处理

1. 从当前会话重新读取账号 ID，不接受客户端传入用户 ID。
2. 校验衣着偏好枚举和城市长度。
3. 服务端解析城市，要求中国境内有效结果，并得到规范城市名、行政区、经纬度和时区。
4. 更新当前账号唯一 `user_preferences` 行。
5. 删除当前账号当日推荐，使下一次生成使用新上下文。
6. 重新验证设置、偏好和推荐页面。

## 返回

```text
status: idle | success | error
message: 面向用户的中文结果
```

## 错误约定

- 未登录或会话失效：`当前会话已失效，请刷新后重试。`
- 城市为空或格式错误：`请输入完整城市名，例如武汉。`
- 城市无匹配：`没有找到这个中国城市，请检查名称后重试。`
- 城市服务不可用：`城市暂时无法确认，请稍后重试。`
- 数据保存失败：`个性化设置暂时无法保存。`

任何错误都不得覆盖账号原有偏好或城市。
