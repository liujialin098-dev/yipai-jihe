# SDD-042：统一标题与精简说明

状态：本地完成，未部署；2026-09-09。用户要求：衣物贴纸册居中，类似宣传/介绍文字不显示，统一所有标题样式。

## 功能边界

- 页面标题按可用内容宽度居中，日期、数量及装饰不得令标题偏移。统一现有圆润标题字体、字重与字距，保留页面/分区/卡片的三级字号。
- 首页Hello与Ensemble继续使用已确认的Fredoka品牌字形，字号与页面级标题一致；不更换品牌、配色、导航或动效。
- 删除贴纸、资讯、衣库、添加/编辑、日记、偏好、登录入口的重复介绍语；不使用全局隐藏p或app-page-lead的办法。
- 资讯来源、日期、简述性质及外链仍保留，推荐依据移入默认折叠的内容详情。错误、状态、表单标签、身份风险、天气来源及空状态行动提示保持可用。
- 不改变鉴权、数据读写、推荐/天气/贴纸流程，不调用付费服务。此次仅本地修改，不自动部署。

## 验收

1. 衣物贴纸册标题中心与内容中心一致；资讯、衣橱、日记标题一致。
2. 用户指定介绍语及同类页面引导语不渲染；错误与真实来源仍可见/可展开。
3. 320/375px和横屏、日夜模式无水平溢出；长标题自然换行，h1/h2/h3语义不混用。
4. check/build/042及相关回归通过；固定样本/浏览器证据不冒充账号端到端。
