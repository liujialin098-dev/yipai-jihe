# Contract: 推荐页天气城市交互

## 页面展示

- 当前城市区分“本次使用”与“常用城市”。
- 有有效 IP 建议时显示：近似城市、误差说明、“本次使用”和“设为常用城市”。
- 临时城市生效时显示“恢复{常用城市}”；账号没有常用城市时显示“清除本次城市”。
- IP 建议不可用时不显示空提示或失败警告，保留手动“选择城市”。

## 城市确认动作

输入：

```text
city: 2～40 字符城市名
mode: session | saved
```

处理契约：

1. 从当前服务端会话获取用户，不接受客户端用户 ID。
2. 重新解析中国城市并获得规范五元组。
3. `session`：删除当前用户旧推荐后写入账号绑定会话 Cookie，不更新账号城市。
4. `saved`：删除当前用户旧推荐，更新当前用户账号城市，成功后清除临时 Cookie。
5. 任一步失败返回通俗错误；不得使用表单提供的坐标或时区。

## 恢复动作

1. 从当前服务端会话获取用户。
2. 删除当前用户旧推荐。
3. 清除临时 Cookie。
4. 刷新推荐页；若有常用城市则恢复，否则提示用户手动选择。

## 推荐一致性

- 页面读取、目标日期计算和生成动作必须使用同一当前有效城市。
- 已保存推荐的天气城市不等于当前有效城市时不得展示。
- 真实天气服务失败时停止生成，不显示旧城市或模拟天气。
