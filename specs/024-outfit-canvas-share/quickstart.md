# Quickstart: 穿搭画布与分享卡片

## 前置条件

1. `.env.local` 中当前 Supabase 配置可用。
2. 当前账号至少有一套包含 2 件以上有效衣物的推荐。
3. 应用迁移已应用，`outfit_canvases` 与 `wardrobe_items.cutout_path` 可读写。

## 自动门禁

```bash
npm run check
npm run build
npm run verify:sdd-024
```

预期：格式、lint、类型和构建通过；固定样本抠图、布局边界、JSON 校验、无人物主路径、双账号 RLS、Storage 路径隔离和原图回退全部通过。

## 390px 浏览器验收

1. 登录后打开 `/recommendations`，任选一套点击“编辑穿搭卡片”。
2. 核对画布只显示衣物，没有人物、人体轮廓或自动生成模特图。
3. 选择一件衣物，完成拖动、缩放、旋转、前移、后移和恢复排布。
4. 对白底衣物执行本地抠图，确认处理中有明确状态，完成后背景透明；刷新后仍优先使用抠图。
5. 对复杂背景样本模拟失败，确认保留原图且仍可保存。
6. 修改名称和背景色，保存后刷新，确认布局完全一致。
7. 导出分享图，核对尺寸至少 1080px、衣物位置一致、没有账号私密信息。
8. 检查页面 `scrollWidth <= innerWidth`、控制台无 error、拖动时页面不跟随滚动。
9. 启用减少动态，重复选择和拖动，确认功能仍完整。

## 隔离验收

- 账号 A、B 各自保存一张画布并上传一张抠图。
- A 读取、更新、删除 B 的画布均失败。
- A 为 B 的衣物保存抠图路径失败，创建 B 私有路径签名 URL 失败。
- 测试完成后清理合成账号数据和测试图片。
