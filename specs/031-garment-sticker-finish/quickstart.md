# Quickstart: 衣物纸贴质感验收

## 前置条件

- 本地 `.env.local` 可读取当前 Supabase 项目。
- 测试账号至少包含一件已有透明图的衣物和一件只有原图的衣物。
- 不需要调用百度抠图、AI 识别或推荐模型。

## 自动检查

```powershell
npm run check
npm run build
npm run verify:sdd-031
```

预期：三个命令全部退出码为 0；验证脚本确认共享组件、透明/原图双状态、衣橱与推荐接入、无图片修改和减少动态边界。

## 390px 浏览器验收

1. 打开 `/wardrobe`，找到一件透明底衣物。
2. 确认衣物周围有连续白边，背景有低对比度纸纹，阴影轻且带紫调。
3. 找到一件只有原图的衣物，确认显示为圆角纸卡，没有错误的衣物轮廓。
4. 打开 `/recommendations`，确认三套推荐单品沿用相同材质，收藏按钮和角色标签没有被遮挡。
5. 展开“换一件”，确认候选图片沿用相同规则，提交操作可用。
6. 核对页面 `scrollWidth` 不大于视口宽度，控制台无 error。
7. 开启减少动态后再次悬停或点按，确认没有位移或缩放跳动。

## 数据与安全复核

- 不执行数据库迁移。
- 不新增环境变量。
- 不修改 `image_path`、`cutout_path` 或任何 Storage 对象。
- 不显示原始私有路径、用户 ID 或签名参数。
