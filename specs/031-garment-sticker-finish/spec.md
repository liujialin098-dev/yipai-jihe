# Feature Specification: 衣物纸贴质感

**Feature Branch**: `master`

**Created**: 2026-09-07

**Status**: Ready

**Input**: User description: "为衣物展示添加白色描边、阴影或纸张纹理。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 衣物像真实纸质贴纸 (Priority: P1)

用户浏览衣橱或每日推荐时，透明底衣物应呈现清晰但克制的白色轮廓、轻微立体阴影和纸张触感，使衣物从背景中自然分离，同时保持原款式与颜色不变。

**Why this priority**: 衣物是产品的主要视觉内容，贴纸质感直接影响时尚感、识别度和品牌完成度。

**Independent Test**: 使用至少一件透明底衣物分别打开衣橱和推荐页，观察轮廓、阴影与纹理，并与原图核对款式和颜色。

**Acceptance Scenarios**:

1. **Given** 衣物存在可用透明底图，**When** 用户查看衣橱卡片，**Then** 衣物周围显示连续白色轮廓和轻柔的带色阴影，主体没有被裁切或改色。
2. **Given** 推荐套装包含透明底衣物，**When** 用户查看搭配单品，**Then** 每件衣物使用一致的纸贴材质，并保持角色标签和收藏操作可用。
3. **Given** 页面显示多件贴纸衣物，**When** 用户滚动或悬停，**Then** 视觉层级稳定，没有高亮闪烁、强烈发光或明显性能卡顿。

---

### User Story 2 - 原图优雅降级 (Priority: P2)

当衣物只有普通照片时，用户仍能看到与贴纸体系协调的纸张卡面和轻阴影，而不会出现错误的轮廓、透明底假象或不可读内容。

**Why this priority**: 现有衣橱同时包含演示原图和用户实拍图，视觉升级不能依赖所有图片都已完成去背。

**Independent Test**: 使用一件没有透明底图的衣物打开衣橱和推荐页，确认照片完整、卡面统一且不会误加衣物外轮廓。

**Acceptance Scenarios**:

1. **Given** 衣物没有透明底图，**When** 用户查看该衣物，**Then** 系统使用圆角纸卡、白色内边和轻阴影承载原图，不把照片背景误当作衣物轮廓。
2. **Given** 图片暂时不可用，**When** 页面展示空图状态，**Then** 原有名称或缺图提示仍清晰可读，布局不塌陷。

### Edge Cases

- 极浅色或白色衣物必须能通过阴影从白色描边和浅背景中区分出来。
- 细肩带、鞋带、镂空和配饰等细小边缘不得因轮廓处理而大面积糊成白块。
- 极宽、极高或不规则比例的图片必须完整包含在既有卡片范围内。
- 深色模式或减少透明度设置下，衣物主体和边界仍需清晰。
- 触屏设备没有悬停状态时，不影响静态贴纸效果和操作按钮。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 为可用的透明底衣物显示连续、克制的白色外轮廓。
- **FR-002**: 系统 MUST 为衣物贴纸显示与当前浅紫背景协调的柔和阴影，阴影不得使用纯黑重投影或霓虹发光。
- **FR-003**: 系统 MUST 在贴纸承载层显示低对比度纸张纹理，纹理不得覆盖或改变衣物主体像素。
- **FR-004**: 系统 MUST 优先展示当前衣物的透明底版本，并在其不可用时自动使用原图。
- **FR-005**: 对普通原图，系统 MUST 使用圆角纸卡降级，且 MUST NOT 伪造衣物轮廓。
- **FR-006**: 衣橱列表与推荐搭配单品 MUST 复用同一套贴纸视觉规则。
- **FR-007**: 现有收藏、查看详情、角色标签和换件操作 MUST 保持可用。
- **FR-008**: 贴纸效果 MUST 不增加新的用户配置步骤，不修改衣物数据、图片文件或账号权限。
- **FR-009**: 贴纸效果 MUST 适配 320px 及以上移动端宽度，并不得造成水平溢出或图片裁切。
- **FR-010**: 在用户请求减少动态时，系统 MUST 保持静态材质并取消非必要的位移或缩放反馈。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 衣橱和推荐页中 100% 的可用透明底衣物呈现相同的白边、轻阴影和纸张质感。
- **SC-002**: 100% 的无透明底衣物使用原图降级卡面，且不出现错误外轮廓。
- **SC-003**: 在 390px 视口下，衣橱与推荐页面无水平溢出，衣物、标签和收藏按钮均保持完整可见。
- **SC-004**: 使用透明、浅色、深色和复杂背景四类固定样本验收时，衣物主体颜色与款式保持不变，边缘无明显截断。
- **SC-005**: 贴纸升级后，用户从衣橱进入单品详情、在推荐中收藏或换件的关键操作成功率保持 100%。

## Assumptions

- 当前项目已能为部分衣物提供透明底图，并可为其余衣物提供原图。
- 本阶段只升级展示材质，不重新开放专业去背、人工精修、自由画布或分享卡片入口。
- 白色轮廓、轻阴影和纸张纹理作为一套统一材质共同启用，不增加用户切换选项。
- 本阶段不修改数据库结构、图片文件或第三方服务配置。
