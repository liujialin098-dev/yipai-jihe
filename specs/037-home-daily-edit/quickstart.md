# 验收

1. 运行 `npm run check`、`npm run build`、`npm run verify:sdd-037` 与 036/032/033/015/007 静态回归。
2. 登录已有测试身份打开本地首页：只有今日穿搭和五日手帐两个业务区域，无资讯/衣橱计数/账号大卡和功能说明。未登录入口网关不变。
3. 无推荐时明确标注“衣橱单品 · 还未生成今日搭配”，点击“搭一套”进入今日推荐，不自动调用 AI。已保存当日有效推荐时只展示该推荐第一套的真实单品和原始标题。
4. 天气成功显示真实值与来源时间；5 分钟失效后隐藏温度、显示待刷新；未选城市/失败不生成默认天气。完整天气页面保持原样。
5. 五日条包括今天，点击往日进入 `/diary/new?date=对应日期`。已有记录显示当前可见单品，收藏优先；无图/已移除记录仍保留记录入口。无记录仅显示加号。
6. 390px 日夜截图、320px 无溢出、最低44px入口与五天日期核对。恢复浏览器默认尺寸，不改账号或衣物。

固定样本已覆盖实际 DailyEdit 组件的 3～7 件推荐、空衣橱、读取错误、体验/正式身份、日记显示，以及跨月/跨年/闰年和代表单品过滤。这不等同于重新调用真实模型生成推荐；本次不新增任何数据库、衣物或日记记录。
