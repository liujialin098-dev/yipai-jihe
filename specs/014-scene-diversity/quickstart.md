# Quickstart: 场景差异化推荐验收

## 前置条件

- 当前仓库依赖已安装。
- `.env.local` 保留既有 Supabase 与 OpenAI 服务端配置。
- 不需要数据库迁移或新增环境变量。

## 自动验收

```powershell
npm run check
npm run build
npm run verify:sdd-014
```

回归既有推荐、个性化和真实天气：

```powershell
npm run verify:sdd-005
npm run verify:sdd-012
npm run verify:sdd-013
```

## 固定样本预期

1. 通勤、休闲、约会、正式各生成三套完整方案。
2. 12 套方案均至少有两个场景信号。
3. 正式方案不包含仅运动单品。
4. 可选配饰和外套不使用当前场景明确不推荐的风格。
5. 六组场景两两核心单品重合度均不超过 50%。
6. 男装模式不使用裙装，四场景仍可完成。
7. 小衣橱不足时不伪造衣物，保持现有明确提示。

## 手工验收

1. 打开 `/recommendations?day=today`。
2. 在相同天气下依次选择通勤、休闲、约会和正式并生成。
3. 确认通勤偏利落、休闲偏放松、约会有精致重点、正式无跑鞋等明显雷区。
4. 确认不是只更换标题或配饰，核心上装、下装、鞋或外套有可见变化。
5. 切换今天与明天，确认真实天气与日期逻辑未被改变。

## Production 验收

阶段完成并提交后发布到既有 `yipai-jihe` Production，检查：

- 固定域名与核心页面返回 200。
- 新匿名会话可加载演示衣橱并生成四场景结果。
- Vercel 最近 30 分钟无 error 日志。
