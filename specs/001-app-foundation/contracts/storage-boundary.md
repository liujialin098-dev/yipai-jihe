# 私有 Storage 边界契约

## 路径格式

```text
wardrobe-images/<auth.uid()>/<file-name>
```

未来需要业务子目录时可使用：

```text
wardrobe-images/<auth.uid()>/<business-id>/<file-name>
```

无论采用哪一种，对象名的第一段始终是当前用户 UUID。

## 必须满足

- bucket 必须保持私有，不提供公开 URL。
- 已登录用户只能在第一段等于自身用户 ID 的路径上执行读取、插入、更新和删除。
- 更新操作必须同时验证旧路径和新路径均归当前用户。
- 未登录请求和跨用户路径请求必须失败，不得只依赖界面隐藏入口。
- 本阶段的验收只创建无敏感内容的文本测试对象；不提交或上传真实个人照片。

## 明确不承诺

- 本阶段不定义图片尺寸、格式、压缩、抠图或 CDN 转换规则。
- 本阶段不提供上传接口或衣物记录与图片的业务关联。
