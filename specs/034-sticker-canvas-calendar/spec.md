# Feature Specification: 贴纸画板与月历

**Feature Branch**: `master`

**Created**: 2026-09-07

**Status**: Ready

**Input**: User description: "在贴纸页面增加无格子的自由画板，贴纸可移动、缩放、旋转和重叠，完成后可下载或分享；增加按月用每日代表衣物贴纸展示穿搭记录的日历与统计。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 自由制作衣物贴纸画板 (Priority: P1)

用户从当天选择的衣物贴纸开始，在无格子的画板上直接拖动衣物，通过明确控件调整大小、角度和前后层级，并允许贴纸相互重叠。

**Why this priority**: 自由排布是本轮最核心的新价值，决定贴纸页是否从展示页升级为创作工具。

**Independent Test**: 选择 1～8 件已有透明图的衣物，拖动任意贴纸，调整大小、旋转和层级，刷新后确认当天有效布局恢复且无格子或自动吸附。

**Acceptance Scenarios**:

1. **Given** 用户已选择衣物，**When** 拖动贴纸，**Then** 贴纸持续跟随指针并停留在画板范围内。
2. **Given** 两件贴纸发生重叠，**When** 用户调整置顶或置底，**Then** 两件贴纸的遮挡关系立即改变。
3. **Given** 用户不能或不便拖动，**When** 使用方向、缩放和旋转控件，**Then** 可完成与手势等价的调整。
4. **Given** 用户刷新当天页面，**When** 衣物仍属于当前可见衣橱，**Then** 当天布局恢复；失效衣物自动剔除。

---

### User Story 2 - 下载或分享贴纸成品 (Priority: P1)

用户完成排布后，可以下载清晰图片；设备支持系统分享时，也可以直接调用分享面板发送同一张图片。

**Why this priority**: 可带走的成品让创作形成完整闭环，也是参考页面最有价值的传播能力。

**Independent Test**: 完成一张全部使用透明贴纸的画板，分别点击下载和分享，确认输出图片保持背景、位置、大小、角度与层级，不包含账号或私有字段。

**Acceptance Scenarios**:

1. **Given** 画板至少有一张已完成贴纸，**When** 点击下载，**Then** 浏览器下载一张 4:5 高清 PNG。
2. **Given** 设备支持文件分享，**When** 点击分享，**Then** 系统分享面板收到该 PNG。
3. **Given** 仍有衣物未完成去背，**When** 查看导出操作，**Then** 页面提示先完成贴纸，不把普通照片伪装为透明贴纸成品。

---

### User Story 3 - 查看每月衣物贴纸日历 (Priority: P2)

用户切换到月历，按自然月查看真实穿搭日记：每天用一件代表衣物贴纸显示当天记录，并看到本月记录天数、代表单品数量和最常出现的代表单品。

**Why this priority**: 月历把日记与贴纸连接起来，形成比数字报表更直观的长期回顾。

**Independent Test**: 准备同月多天穿搭日记和部分单品收藏，确认每个记录日出现一张当前可见贴纸；当天穿搭含收藏时优先展示收藏，否则展示当天第一件，并核对月度统计。

**Acceptance Scenarios**:

1. **Given** 某天有穿搭日记，**When** 查看对应月份，**Then** 日期格显示当天代表衣物贴纸和衣物件数提示。
2. **Given** 当天日记包含已收藏单品，**When** 生成代表贴纸，**Then** 优先使用当天最先出现的收藏单品；否则使用当天第一件衣物。
3. **Given** 用户切换月份，**When** 新月份载入，**Then** 只展示当前账号该月真实日记，不补造未来或缺失记录。
4. **Given** 某天没有日记，**When** 查看日期格，**Then** 保持留白并可进入该日期的手工记录入口。

### Edge Cases

- 仅选择一件衣物时仍可编辑与导出。
- 达到 8 件上限后不得继续添加；移除后可再次选择。
- 贴纸拖到边缘时保留可见主体，不得完全移出画板。
- 拖动与页面滚动不得互相误触；画板外仍可正常滚动。
- 导出中图片加载失败时不下载残缺图片，并保留当前画板。
- 浏览器不支持文件分享时，分享操作必须明确降级为下载。
- 月历必须按周一到周日排列，正确处理月初偏移、闰年和 28～31 天月份。
- 已归档或不可见衣物不再展示真实图片，但不得导致整个月历失败。
- 320px 以上视口不得横向溢出；主要控件触达区域至少 44px。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: `/stickers` MUST 提供“画板”和“月历”两个清晰视图，切换不丢失当天选择或布局。
- **FR-002**: 画板 MUST 使用无格子、无吸附的连续空间，支持 1～8 张当前账号衣物贴纸。
- **FR-003**: 用户 MUST 能直接拖动贴纸，并通过控件调整位置、缩放、旋转和前后层级。
- **FR-004**: 贴纸 MUST 允许重叠，选中状态必须同时使用轮廓与控件状态表达，不能只依赖颜色。
- **FR-005**: 画板 MUST 提供恢复排布，并按账号短标识与自然日把布局保存在当前设备；恢复时必须与服务端可见衣物取交集。
- **FR-006**: 只有透明贴纸全部就绪时才允许导出，下载 MUST 生成 1080×1350 PNG。
- **FR-007**: 分享 MUST 优先使用设备原生文件分享；不支持时 MUST 降级为下载并明确反馈。
- **FR-008**: 导出图片 MUST 保持画板背景、位置、大小、旋转和层级，且不得包含邮箱、用户 ID、私有路径或内部字段。
- **FR-009**: 月历 MUST 只使用当前账号该月真实穿搭日记，不新增模拟记录。
- **FR-010**: 每个有日记的日期 MUST 选择一件代表衣物：当天衣物中已收藏者优先，否则使用日记顺序中的第一件。
- **FR-011**: 月历 MUST 展示记录天数、不同代表单品数和出现最多的代表单品；并支持前后月份切换。
- **FR-012**: 缺少当前图片的历史衣物 MUST 使用克制占位，不得泄露 Storage 路径或阻断其他日期。
- **FR-013**: 拖动 MUST 有按钮或键盘替代；所有图标按钮必须有可读名称、可见焦点和至少 44px 触达区域。
- **FR-014**: 减少动态时 MUST 取消非必要位移、弹性和旋转过渡，但保留状态反馈。
- **FR-015**: 本阶段 MUST NOT 增加 Reel、视频、MP4、直播、转盘、烟花播放、自动轮播或社交公开发布。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可在 60 秒内完成选择、排布并下载一张贴纸图片。
- **SC-002**: 画板上 100% 贴纸可通过拖动和非拖动控件两种方式调整，且支持任意两件重叠。
- **SC-003**: 下载图片尺寸固定为 1080×1350，肉眼核对与屏幕布局的位置、旋转和层级一致。
- **SC-004**: 月历中 100% 有效日记日均显示一件代表衣物，统计数字与当月日记一致。
- **SC-005**: 390px 视口下无水平溢出，主要控件无遮挡，浏览器无运行错误。

## Assumptions

- “每天最喜欢的某一件单品”使用既有单品收藏表达：当天穿搭内若有收藏则优先，否则使用日记的第一件，不新增重复的每日收藏数据。
- 自由画板布局属于当日轻量创作状态，保存在当前设备，不新增跨设备画板同步或公开作品。
- 月历只消费穿搭日记；未来日期和无记录日期保持空白。
- 参考图仅用于功能信息架构与贴纸密度，不复制品牌、配色、名称或专有玩法。
