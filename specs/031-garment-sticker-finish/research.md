# Research: 衣物纸贴质感

## 决策 1：白边只用于透明底图

- **Decision**: 只有 `cutoutUrl` 存在时才绘制贴合透明通道的白色轮廓层。
- **Rationale**: 普通照片的透明通道只包含整张矩形，直接加白边会把照片边框误当作衣物轮廓。
- **Alternatives considered**: 对所有图片统一使用滤镜；自动在浏览器重新抠图。前者视觉错误，后者会重新引入已退役能力和计算成本。

## 决策 2：双图层建立轮廓，不修改真实衣物像素

- **Decision**: 透明图后方复用同一图像作为白色轮廓层，前方保留原图，并让浏览器缓存同一资源。
- **Rationale**: 轮廓层与透明通道天然一致，真实衣物层不需要滤色或重绘，款式和颜色保持原样。
- **Alternatives considered**: 多方向投影滤镜；服务端生成永久白边图片。多重滤镜在细节处容易变糊，永久图片会增加存储和版本管理。

## 决策 3：纹理放在承载层，不覆盖衣物

- **Decision**: 使用低对比度、固定位置的 CSS 纸纤维纹理作为背景层，衣物位于其上方。
- **Rationale**: 可以产生纸张触感，同时不污染衣物颜色，也不需要下载额外纹理资源。
- **Alternatives considered**: 半透明噪点覆盖整张图片；位图纹理。覆盖层会改变衣物观感，位图增加请求和资源维护。

## 决策 4：阴影使用带紫调的双层软阴影

- **Decision**: 使用小范围接触阴影加大范围丁香紫环境阴影，不使用纯黑硬阴影。
- **Rationale**: 与当前浅紫背景和时尚四色体系协调，浅色衣物也能从白边中分离。
- **Alternatives considered**: 纯黑投影；霓虹外发光。两者都与当前高级、克制的品牌方向冲突。

## 决策 5：无透明图使用纸卡降级

- **Decision**: 原图保持完整矩形，通过圆角、白色内边、纸纹和轻阴影与贴纸体系协调。
- **Rationale**: 明确告诉用户这是原图，同时让混合数据的列表仍然统一。
- **Alternatives considered**: 隐藏无透明图衣物；直接裁切为 contain。前者破坏核心数据可见性，后者可能留下突兀背景。
