# SDD-051 自适应底栏与灵感偏好修复

## 核心链路

- 滚动页面：底栏在品牌色背景上为白色，覆盖浅色卡片时切换为品牌色表面；图标始终可辨认，中央添加按钮继续青柠色。
- 打开灵感偏好：八个主题居中排布，可点选/取消，保存后刷新保留；至少选择一个主题。保存失败不得重置选择。
- 时尚灵感标题区：使用独立纸面卡片及边界，与纯色页面背景分离。

## 验收

- 底栏仅交叉淡化背景层，不位移/缩放；快速反向滚动不重播闪烁，减少动态模式无位移动画。
- 浅色卡片覆盖检测随滚动、窗口尺寸、路由、内容展开、皮肤切换更新，不持续轮询，不读取图片像素。
- 原有六主题加街头风格、配饰细节；同步白名单、分类、卡片映射和数据库约束。旧选择不变，新增账号默认八项。
- 手机320/375px、横屏、日夜模式和替代皮肤无横向溢出；操作区至少44px，键盘能选择。
- 静态检查、生产构建、真实组件隔离交互及数据库约束验证；不将隔离测试当真实账号端到端。

## 不包含

不改顶部导航、账号安全、资讯源、系统权限及其他贴纸逻辑；不发送邮件或修改真实用户偏好，不自动发布前端。
