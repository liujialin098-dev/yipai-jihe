# SDD-029 个人穿搭作品集视觉调整

日期：2026-09-06。需求：参考 Whering 个人穿搭主页的风格，但保持衣拍即合自己的辨识度。

## 核心链路

打开个人主页 → 查看头像昵称和真实统计 → 浏览近期穿搭卡片 → 进入已有自由画布；点击编辑资料后，继续使用原有头像和昵称保存流程。

## 范围与验收

- 个人主页采用纯色封面、身份摘要、紧凑横排统计、清晰的衣物作品区；不再默认展开编辑表单。
- 展开编辑后保留头像选择、昵称校验、保存反馈；收起编辑不能提交更改。
- 穿搭缩略图复用真实衣物和历史位置/旋转/尺寸，标题移到图片外；不引入模特、虚构作品或他人图片。
- 保留四项真实统计、私密说明、设置入口；衣橱、日记、收藏入口只链接已有路由。近期作品仍最多四张，明确说明而不冒充全部作品。
- App 底色采用浅丁香到冷白的轻渐变（用户本轮确认，覆盖首版纯冷白决定），四色用于固定角色的点缀；保留品牌、底部 Dock、原路由和导航名称。
- 390px 与桌面无横向溢出；编辑可通过键盘展开；遵循减少动态；尊重项目已配置的固定浅色主题，系统深色模式不改变 App 阅读底色；空衣橱与缺图有可读提示。
