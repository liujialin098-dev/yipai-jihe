# UI Contract: 衣物贴纸册

## Page

- 页面标题：`衣物贴纸册`
- 副标题只说明结果：挑出今天想穿或喜欢的衣物，做成白边贴纸。
- 顶部贴纸板始终可见；空状态引导从下方选择。

## Sources

- `今日想穿`：当前账号全部可见活跃衣物。
- `我的喜欢`：当前账号仍有效的单品收藏。
- 切换来源不清空已选衣物。

## Selection

- 每个衣物选择区域至少 44px，可通过文字和勾选状态识别，不能只依赖颜色。
- 最多选择 8 件；达到上限时保留现有选择并给出说明。
- 只有原图的衣物显示“待生成”，已有透明图显示“贴纸就绪”。

## Processing

- 主按钮文案包含待生成数量。
- 处理时显示总体件数和当前衣物状态，不使用只会循环的假进度。
- 失败保留原图，并显示可再次点击的重试状态。

## Visual

- 透明衣物使用 loose 白边纸贴，不显示矩形底板。
- 贴纸板使用浅丁香紫、冷白和少量青柠点缀，不复制参考产品。
- 贴纸允许小幅固定角度形成手工陈列感，但不提供拖拽、旋转、缩放。
- 减少动态时取消进入位移和选择缩放。
