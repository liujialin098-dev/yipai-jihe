# 实现计划

最新视觉推敲：问候居中，Hello复用 `brand-name-english` 的本地Fredoka字体和顶部650粗体；日期/天气12px同行居中，来源保留44px入口。移除所有气泡底板，已就绪透明衣物在同一连续区域以白边、轻阴影与轻微交叠形成整体拼图。无推荐时选最多8件就绪贴纸；有推荐只取本套就绪贴纸并展示完成数。没有贴纸时链接 `/stickers`，不在首页自动调用抠图。按数量调整布局，不新增随机轮播或数据写入。

设计：浅紫背景 #f7f3fb、白色 #ffffff、墨色 #27222d、丁香 #d8cbea、青柠 #e5f69b；复用主题变量的日夜配对，不增加全局色板。标题沿用 ZCOOL，正文沿用系统中文与 Fredoka 数字；唯一视觉特色为原有衣物的松散排布，不新增装饰编号或广告语。

布局：顶部导航 → 标题/日期/精简天气 → 无格衣物排布或真实空状态 → 一项主操作 → 五日贴纸手帐 → 每日推送轻量入口 → 体验身份保存提示 → 底部导航。推送入口整行可点，浅紫表面配青柠图标，使用日夜语义颜色，关闭预取；只链接现有资讯页，不新增请求或通知权限。约两屏以内，主要内容不再重复套卡。

实现：保持 Server Component；复用 getRecommendationPageData 与 getDiaryMonthData（跨月时读取两个月），纯函数生成日期条与代表单品。天气组件复用同一加载/过期/取消逻辑。主拼图只接受cutoutUrl并使用GarmentSticker loose；日记缩略图仍保持原图安全降级。不存在透明图时不能假装已抠图。

验收：固定日期跨月/跨年、收藏优先、缺图/已移除、3～7 件布局边界、未登录网关、过期天气展示；check/build、036/037 回归，真实本地窄屏和日夜截图、导航点击。
