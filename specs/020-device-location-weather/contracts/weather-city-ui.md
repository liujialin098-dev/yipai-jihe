# Contract: 天气城市定位 UI

## 显示

- 城市选择面板内新增“使用当前位置”区块，不增加新的页面或导航。
- 常态说明：仅在点击后请求定位，只用于城市级天气，精确位置不保存。
- 提供两个明确按钮：“本次使用当前位置”“设为常用城市”。
- 显示 BigDataCloud 城市定位说明和官方接口链接，并明确衣拍即合只接收城市名。

## 交互

- 点击任一按钮后进入共享 pending，禁用两个定位按钮并显示“定位中”。
- 成功后显示城市级结果，由 Server Action 刷新页面城市状态。
- 权限拒绝：提示在浏览器设置中允许定位，或手动选择城市。
- 定位不可用：提示设备暂时无法提供位置，可重试或手动选择。
- 定位超时：提示定位超时，可到信号较好处重试或手动选择。
- 不支持/非安全上下文：提示当前浏览器无法定位，直接使用手动选城。

## 无障碍与移动端

- 状态反馈使用 `aria-live="polite"`。
- 定位按钮最小高度 44px，390px 宽度下保持两列；极窄宽度可自然换行，不横向溢出。
- pending 图标仅表达等待，不使用白色扫光或统一弹跳。
- 不使用 Effect 或页面加载脚本触发定位。
