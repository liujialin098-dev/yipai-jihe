# Quickstart: SDD-026 独立验收

## 准备

1. 在 `.env.local` 配置服务端 `PHOTOROOM_API_KEY`，不得使用 `NEXT_PUBLIC_` 前缀。
2. 保持现有 Supabase URL、publishable key 和私有 `wardrobe-images` bucket 配置。
3. 运行 `npm run dev`，使用两个隔离测试账号。

## 自动专业去背

1. 用账号 A 添加纯色棚拍、复杂室内、白衣白底、黑衣暗底、鞋和配饰样本。
2. 确认入库，预期页面立即显示入库成功，不等待专业去背。
3. 稍后打开衣橱/画布，预期成功样本优先使用自动裁边透明 PNG，原图仍可读取。
4. 对已有透明图普通请求，预期返回复用且不再次调用；主动“重新抠图”才允许重做。
5. 临时移除密钥或模拟超时，预期入库、衣橱、推荐和画布继续使用旧透明图或原图。

## 无格子自由画布与分类尺寸

1. 选择上衣、裤装、外套、鞋和配饰创建穿搭卡片。
2. 预期各品类初始尺寸自然，画布没有方格或吸附。
3. 自由拖动、旋转、缩放和调层级，保存并刷新。
4. 预期全部相对位置、角度、大小和层级一致。

## 人工擦除/恢复

1. 选择已有透明图衣物进入“边缘精修”。
2. 用擦除画笔删除残余背景，再用恢复画笔找回误删衣角，切换三档画笔。
3. 点击重置，预期回到进入精修时状态；点击取消，预期不覆盖透明图。
4. 再次精修并保存，预期成功后画布立即使用新结果，刷新仍存在。

## 视觉与账号隔离

1. 在 390px 宽度检查未登录页、首页、衣橱、推荐、画布和个人主页。
2. 预期背景为丁香紫舞台与有限青柠/珊瑚/天空蓝高光，无水平溢出，内容卡片可读。
3. 开启减少动态和减少透明度，预期功能不变。
4. 用账号 B 请求账号 A 衣物去背、文件和画布，预期全部拒绝。

## 质量命令

```bash
npm run check
npm run build
npm run verify:sdd-026
```

没有 PhotoRoom 密钥时，静态门禁和失败回退仍必须通过；真实 10 张质量验收保持待配置密钥后执行，不得伪造成功结果。
