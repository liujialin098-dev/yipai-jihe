# 独立验收

## 自动检查

运行 `npm run check`、`npm run verify:sdd-036`、`npm run verify:sdd-035`、`npm run verify:sdd-034`、`npm run verify:sdd-030`、`npm run build`。

036 覆盖导航纯数据、左右方向/边界、主题七组首屏与存储异常样本、暗色对比度、手势保护和取消选择合同。030 的模型部分使用模拟接口，不产生模型费用。

## 浏览器

1. 使用隔离体验身份；导航顺序应为首页/推荐/添加/贴纸/资讯，无可见文字，键盘和读屏仍有名称。
2. 顶部收藏应打开 `/diary?view=favorites`；日记和利用率页签仍可进入。中央添加到 `/wardrobe/new`。
3. 顶部月亮/太阳切换日夜并刷新；系统主题与已选主题不同也应尊重已选主题。深色文字清晰，衣物不反色，画板自选底色不变。
4. 在首页标题附近向左拖至少80px，进入推荐；反向返回。小于80px、纵向和边缘拖动不导航。手动链接仍可用；添加表单不启用页面拖动。
5. 贴纸默认无框。选择已有衣物，再点画板衣物显示四角控件；拖动衣物应保持贴纸页。点空白或 Escape 后控件消失，衣物数量和布局不变。
6. 320/375/390px和横屏检查无溢出，顶部44px/底部48px操作区。检查 console error 和数据请求错误覆盖层。

本轮以上核心项通过；系统减少动态、真机多指/边缘手势和Production发布后复验保留在 progress.md，不以桌面模拟冒充真机验收。
