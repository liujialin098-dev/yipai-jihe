# SDD-038：入库即制作衣物贴纸

## 核心链路

选择照片 → 上传/识别或手工核对 → 确认入库 → 添加页自动逐件制作贴纸 → 白边透明预览 → 前往贴纸画板。

- 单件确认与批量确认共用同一流程，仅成功入库才生成，入库结果不依赖抠图成败。
- 复用既有百度专业去背、边缘优化、透明验证和自动裁边；展示复用 GarmentSticker 白色轮廓与阴影，不生成替代衣物图。
- 贴纸依次处理，相邻请求间隔4秒；单件重复点击不得重复排队，失败不自动无限重试，提供显式重试。
- 原图核对区在入库前不改变；就绪后以真实透明图替换预览，并显示排队/制作中/就绪/未完成状态。
- 保留当前账号私有存储、服务端重新鉴权与归属检查，不改变原始图片和入库记录。
- 待处理时提示留在当前页；页面离开取消未开始队列，已经保存的衣物不丢失，可到贴纸页继续。此阶段不建设跨页面持久任务系统。
- 不包含历史衣物自动批处理、新供应商、新表、后台系统通知或Production部署。

## 验收

成功/失败/超时/复用响应、批量串行、重复提交、失败重试、退出清理、单件与批量入库成功后才排队、原图保留、无客户端密钥。真实百度联调取决于本地配置；固定样本不能冒充真实抠图验收。
