# SDD-036：轻盈导航与日夜主题

保持 Ensemble 青柠与丁香紫品牌。底部依次为首页、推荐、添加、贴纸、资讯，仅图标且添加居中。顶部提供衣库、收藏、日夜切换与头像；日记及利用率继续从收藏页签可达。

## 验收边界

- 图标导航保留可访问名称、当前页、焦点与至少 44px 点击区域。
- 日夜切换即时生效并在本设备刷新后保留；首次遵循系统，存储禁用不影响切换。不反转图片或用户自选画板底色。
- 复用本地授权圆润字体，中文清晰；普通浏览页左右滑动，表单、画板、横向滚动区、设备边缘不被劫持；减少动态时关闭位移。
- 画板空白点击或 Escape 隐藏选中框及四角操作；不清空衣物、轮廓、布局或草稿；再次点击继续编辑。
- 不改认证、天气、AI、数据库、导出及生产配置。
