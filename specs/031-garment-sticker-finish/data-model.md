# Data Model: 衣物纸贴质感

## 持久化实体

本阶段不新增或修改持久化实体、数据库字段、Storage 路径或 RLS 策略。

## 现有只读输入

### WardrobeItem

- `id`: 当前账号衣物标识。
- `name`: 图片替代文本和缺图状态文案来源。
- `imageUrl`: 当前用户原图的短期签名地址或公开演示图片地址。
- `cutoutUrl`: 当前用户已有透明图的短期签名地址，可空。

## 派生展示状态

### GarmentStickerState

- `transparent`: `cutoutUrl` 可用。展示透明衣物、白色轮廓、纸纹承载层和软阴影。
- `photo`: 只有 `imageUrl`。展示完整原图、圆角纸卡、白色内边和软阴影。
- `missing`: 两个地址都不可用。由调用方保留原有缺图或名称占位。

## 状态转换

展示状态只在服务端读取数据后派生，不写回数据库。透明图签名地址失效或缺失时，自然降级为原图；两者都缺失时进入缺图状态。
