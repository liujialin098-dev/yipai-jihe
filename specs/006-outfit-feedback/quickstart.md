# Quickstart: 换一件、收藏与偏好反馈

## 自动检查

```bash
npm run check
npm run build
npm run verify:sdd-006
```

预期：

- 两组匿名会话的单品收藏、整套收藏、反馈事件与偏好互相不可读写。
- 同一单品收藏和同一整套收藏连续添加 3 次仍各只有一条。
- 其他用户收藏与偏好读写被 RLS 拒绝；合法/非法替换由 390px 手工流程覆盖。
- 问卷重复提交不重复累计，收藏和换件分数来源可解释。

## 390px 浏览器验收

1. 加载演示衣橱并生成今日三套。
2. 在第一套打开任意单品“换一件”，确认只出现同类、未占用候选；选择后卡片更新且其余两套不变。
3. 刷新页面，确认替换结果保持。
4. 收藏一件单品和一套推荐，进入 `/favorites`，确认两个分区均有真实内容。
5. 取消两类收藏，确认收藏页与原页面状态同步。
6. 打开 `/settings/preferences`，完成 3 题，再执行一次收藏和换件；确认偏好来源显示问卷、收藏、换件。
7. 新会话跳过问卷，确认默认偏好写入且推荐仍可使用。
8. 检查键盘焦点、加载状态、无候选反馈、无水平滚动和控制台错误。

## 暂缓项

- 密码设置、退出和重登录继续等用户集中调试。
- 不喜欢、穿搭日记、协同过滤、模型训练和衣橱外商品不在本阶段。
