# 数据模型：首次账号入口

## 结论

本阶段不新增数据库表、字段或迁移，只明确现有身份状态和允许的转换。

## 身份状态

### 无会话访问者

- 没有有效用户 ID。
- 只能看到账号入口。
- 停留、刷新或切换登录/注册表单不得创建 Auth 用户。

### 体验身份

- 具有稳定 Auth 用户 ID，`is_anonymous = true`。
- 拥有一条同 ID 的资料和偏好记录。
- 可以使用全部 MVP 业务能力，但清除站点数据或换设备后无法恢复。

### 注册账号

- 具有稳定 Auth 用户 ID、邮箱和密码凭据，`is_anonymous = false`。
- 拥有一条同 ID 的资料和偏好记录。
- 可以退出并使用邮箱密码恢复。

## 状态转换

```text
无会话访问者 --明确点击体验--> 体验身份
无会话访问者 --邮箱密码注册--> 注册账号
无会话访问者 --邮箱密码登录--> 已有注册账号
体验身份 --设置页直接注册--> 同一用户 ID 的注册账号
注册账号/体验身份 --退出--> 无会话访问者
```

## 不变量

- 未点击体验前，不存在从无会话访问者自动转为体验身份的转换。
- 直接注册成功必须同时具有用户和有效会话。
- 体验账号升级前后用户 ID 不变，业务数据无需复制。
- 密码不进入 `profiles`、`user_preferences` 或任何业务记录。
- 每个业务查询继续使用当前 Auth 用户 ID 与现有 RLS 所有权策略。
