# Contract: 全局动效语义

| 语义类 | 用途 | 结果 |
|---|---|---|
| `.motion-stage` | 应用内容舞台 | 提供背景气泡层并裁切溢出 |
| `.page-enter` | 页面根节点 | 背景扩散 + 前景显现，700ms 内稳定 |
| `.stagger-item` | 短列表项目 | 最多 8 档、总延迟受限的错峰出现 |
| `.pressable` | 可点击卡片/图标 | 高光和景深反馈，无上下跳动 |
| `.motion-button` | 通用按钮 | 按压填充扩散和光泽通过 |
| `.nav-item` / `.nav-bubble` | 底部导航 | 当前项气泡扩展，图标平滑变色 |
| `.motion-status` | 成功/警告/加载卡 | 柔和显现和状态光晕 |

所有类必须在 reduced-motion 下保留最终状态并关闭持续动画。
