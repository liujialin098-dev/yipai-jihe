# SDD-049：青柠顶部导航

## 目标

让顶部悬浮导航与底部中央添加按钮使用完全一致的品牌青柠色，解决顶部颜色偏淡的问题，同时保持原有圆角、尺寸、结构、皮肤和夜间模式能力。

## 验收标准

- 默认皮肤、五套替代皮肤及其夜间模式的顶部导航均使用品牌青柠 `#d8ff52`。
- 顶部导航不再使用会稀释青柠色的浅色渐变，减少透明效果时颜色也不变化。
- 顶部图标、品牌文字和状态反馈使用深紫前景，普通文字对比度不低于 4.5:1。
- 头像保留独立承托，真实头像不染色；当前页、悬停与按压状态清晰且不引发布局位移。
- 顶部导航保持 72px 高度、36px 圆角和既有入口，不改变底部导航结构、业务数据或账号状态。
