# Quickstart: SDD-025 验收

## 自动检查

```bash
npm run check
npm run build
npm run verify:sdd-025
npm run verify:sdd-024
```

## 390px 手工验收

1. 打开个人主页，核对头像、昵称、四项统计和近期穿搭卡片。
2. 上传 JPG/PNG/WebP 头像并修改昵称，刷新确认保持。
3. 尝试超过 5MB 或非图片文件，确认原资料不被覆盖。
4. 从顶部头像进入个人主页，再进入设置，确认路径清晰。
5. 浏览首页、衣橱、推荐和个人主页，确认四色使用一致、文字清晰、无横向滚动。
6. 开启减少动态与减少透明度，重复资料编辑与导航。

## 数据隔离

- 使用两个匿名测试账号分别写入昵称、头像和穿搭卡片。
- 账号 A 不能读取或更新账号 B 的资料、卡片，也不能签名读取 B 的头像。
- 验收完成后删除测试对象和记录。
