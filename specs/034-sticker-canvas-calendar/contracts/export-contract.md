# Export Contract: 贴纸画板图片

## Input

- 标题：页面内固定的“今日贴纸”视觉标题，不接受账号信息。
- 主题：五种浅色或四种深色画板主题之一。
- 贴纸：1～8 件，包含当前签名图片 URL 和已经限幅的变换数据。

## Output

- MIME：`image/png`。
- 尺寸：1080×1350。
- 内容：主题背景、品牌短标、贴纸位置、大小、旋转和层级。
- 禁止内容：邮箱、用户 ID、私有 Storage 路径、推荐内部字段和调试信息。

## Failure

- 任一图片无法读取或解码时整体失败，不生成残缺文件。
- 分享被用户取消时不显示错误。
- 不支持文件分享时下载同一 PNG，并反馈“已改为下载”。
