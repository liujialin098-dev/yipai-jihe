# Feature Specification: SDD-041 品牌开屏与加载动效

**Feature Branch**: `041-brand-motion`

**Created**: 2026-09-09

**Status**: Approved

**Input**: User description: "根据 app 图标设计一个动图，可以作为加载动画以及开屏动画"

## User Scenarios & Testing

### User Story 1 - 看到品牌开屏成形 (Priority: P1)

用户打开或完整刷新衣拍即合时，先看到由现有青柠与丁香折叠图标自然成形的短开屏，再无跳变地进入原页面，从第一眼建立统一的品牌印象。

**Why this priority**: 开屏是用户对产品的第一次感知，也是本需求最直接的品牌价值。

**Independent Test**: 完整刷新任意公开或登录后页面，观察开屏出现、完成并退出，确认页面内容随后保持原位置且可正常操作。

**Acceptance Scenarios**:

1. **Given** 用户正常打开应用，**When** 首屏开始显示，**Then** 图标以青柠与丁香两部分逐步合拢成现有品牌图形，并显示统一的中英文品牌名。
2. **Given** 开屏正在播放，**When** 动效完成，**Then** 开屏沿与进入一致的视觉路径退出，原页面立即可见且不会再次因站内切页重复播放。
3. **Given** 用户完整刷新或重新打开网页应用，**When** 新的一次页面生命周期开始，**Then** 开屏可重新播放一次。

---

### User Story 2 - 在等待页面时看到品牌加载状态 (Priority: P1)

用户进入需要等待的数据页面时，看到与开屏动作语言一致、但更克制的小型品牌加载动画，明确知道页面仍在准备中。

**Why this priority**: 加载反馈直接影响用户是否把正常等待误认为卡死，并让品牌动效具备日常复用价值。

**Independent Test**: 人为延长页面加载时间，确认加载状态在内容准备期间持续显示、内容完成后立即消失，并且短到几乎无等待的页面不会闪一下加载动画。

**Acceptance Scenarios**:

1. **Given** 页面仍在准备，**When** 等待超过短暂显示阈值，**Then** 用户看到居中的折叠图标循环动效和清晰的等待文案。
2. **Given** 页面很快完成，**When** 等待未超过显示阈值，**Then** 加载动效不会短暂闪烁干扰阅读。
3. **Given** 用户因会话状态被送回账号入口，**When** 跳转正在执行，**Then** 使用同一品牌加载动效而不是不一致的通用旋转图标。

---

### User Story 3 - 在不同设备与辅助设置下舒适观看 (Priority: P2)

对动态敏感、使用深色模式或窄屏设备的用户，仍能看到清晰、稳定且不过度运动的品牌状态。

**Why this priority**: 开屏覆盖整页，必须避免给动态敏感用户造成不适，也不能在夜间模式或小屏幕上破坏品牌辨识度。

**Independent Test**: 分别在减少动态、浅色、深色、320px 窄屏和横屏环境下打开应用，检查动效、对比度和页面边界。

**Acceptance Scenarios**:

1. **Given** 系统启用了减少动态，**When** 开屏或加载出现，**Then** 位移、旋转和循环运动被替换为短暂淡入淡出或静态状态。
2. **Given** 应用处于深色模式，**When** 开屏或加载出现，**Then** 图标原色不反转，背景与文字仍清晰可读。
3. **Given** 设备宽度较窄或横向显示，**When** 动效出现，**Then** 图标、文字与背景都不产生横向溢出或裁断。

### Edge Cases

- 页面在加载动效的延迟期间完成时，动效不得留下残影或占位空白。
- 用户快速前进、后退或切换路由时，开屏不得在站内重复播放，加载状态退出后不得继续占用点击区域。
- 浏览器不支持透明模糊材质时，背景必须降级为稳定纯色或渐变，品牌仍可辨认。
- 图片资源加载失败时，等待状态仍需保留可读文案，不能只剩空白。
- 大字号或中文字体加载较慢时，品牌名不得相互覆盖或超出屏幕。

## Requirements

### Functional Requirements

- **FR-001**: 系统 MUST 复用当前正式 App 图标及其青柠、丁香品牌色，不得创建与正式图标不同的新标识。
- **FR-002**: 系统 MUST 提供一次性开屏动效，表现图标由分离到合拢、品牌名出现、整体平稳退出的完整过程。
- **FR-003**: 开屏 MUST 在单次网页应用生命周期内只播放一次，站内页面切换不得重复遮挡用户。
- **FR-004**: 系统 MUST 提供可复用的页面级加载动效，并用于全局页面加载状态。
- **FR-005**: 会话跳转等待 MUST 复用同一品牌加载动效，替换当前不一致的通用旋转图标。
- **FR-006**: 加载动效 MUST 延迟短暂出现，避免非常短的等待产生闪烁；一旦等待结束必须立即退出。
- **FR-007**: 开屏和加载 MUST 提供可被辅助技术理解的等待状态或等价文本，装饰图层不得被重复朗读。
- **FR-008**: 系统 MUST 响应减少动态偏好，移除大幅位移、旋转和持续循环，仅保留短淡变或静态反馈。
- **FR-009**: 开屏和加载 MUST 同时适配浅色、深色、窄屏、横屏与安全区域，不得改变正式图标颜色或页面业务布局。
- **FR-010**: 动效 MUST 仅使用现有前端能力，不新增动画服务、媒体文件下载、声音或触觉依赖。
- **FR-011**: 本阶段 MUST NOT 替换高频按钮内部的小型提交反馈，也不得改动账号、衣橱、推荐、贴纸或天气数据流。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 标准动态设置下，开屏从出现到完全退出不超过 1.5 秒，完成后页面在 0.1 秒内恢复可操作。
- **SC-002**: 减少动态设置下，开屏在 0.5 秒内完成，且没有可感知的旋转、位移或循环运动。
- **SC-003**: 低于 0.12 秒的页面等待不显示可见加载动画；超过该阈值的等待能够持续显示状态直到页面完成。
- **SC-004**: 在 320px、375px、390px 和横屏宽度下，开屏与加载均无水平溢出、文字重叠或品牌图标裁断。
- **SC-005**: 浅色与深色模式下，品牌图标保持原有青柠与丁香色，等待文字达到清晰可读的对比度。
- **SC-006**: 键盘与屏幕阅读器用户能获知正在加载，且动效退出后不存在继续拦截页面操作的覆盖层。

## Assumptions

- “动图”指应用内可缩放、可响应辅助设置的实时品牌动效，而不是固定 GIF 文件。
- 开屏在每次完整打开或刷新时播放一次；站内路由切换不重复播放。
- 开屏文案使用现有 `Ensemble / 衣拍即合` 双语品牌，不添加广告口号。
- 日常高频按钮继续保留现有轻量提交反馈，品牌动效只用于页面级等待和会话跳转。
- 本阶段不新增数据实体、服务器接口、第三方依赖或生产环境配置。
