# UI Contract

## Sticker canvas

- 画板保持无格子、无吸附并允许重叠。
- 点击贴纸后显示四角控件：左上与右下缩放，右上与左下旋转。
- 每个角控件至少 44×44 CSS px；贴纸中部拖动。
- “置顶”后该贴纸必须覆盖其他重叠贴纸；“置底”后必须被其他重叠贴纸覆盖。
- 裁切模式提供上、右、下、左四边控制、重置和完成操作。
- 下载与系统分享继续输出 1080×1350 PNG，并忠实反映裁切、层级、旋转和缩放。

## Navigation

- 顶部左侧：衣库；中间：品牌；右侧：个人头像。
- 底部：`首页 / 日记 / 贴纸 / 收藏 / 推荐`，全部使用两个汉字。
- 贴纸为中央主操作，视觉优先级最高但不得遮挡页面内容。
- 时尚资讯从首页内容入口继续可达，不再占用底部主导航。

## Diary and favorites

- 日记默认完整显示所选月份日历，空月份也显示全部日期。
- 有记录日期显示一件代表单品贴纸，多件显示数量角标。
- 今天和过去日期可添加/编辑；未来日期不可写入。
- 日历下方显示“添加一件单品”。
- 日记与收藏页均提供醒目的贴纸工作台入口。

## Utilization

- 报告顶部显示最近 30 天贴纸墙。
- 墙内只展示真实日记中出现过的去重单品，最多 24 件并允许视觉重叠。
- 无记录时显示明确空状态和记录入口，不补造贴纸。
