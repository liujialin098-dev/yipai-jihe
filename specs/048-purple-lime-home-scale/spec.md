# SDD-048：紫青柠画板与首页字号层级

## 目标

在不改变衣橱拼图布局、加载时序和导航结构的前提下，让首页的品牌感更鲜明：默认皮肤使用紫色与青柠色的局部色晕，其他皮肤自动使用自身主辅色；放大加载标志与首页文字，并保持稳定的字号层级；底部中央添加按钮统一为品牌青柠色。

## 验收标准

- 默认皮肤的深色衣橱画板包含紫色与青柠色两层局部色晕，保留深色基底和 6px 白色外框。
- 其他五套皮肤分别使用自身 `skin-accent` 与 `skin-secondary` 生成色晕，不统一染成紫青柠。
- 首页字号遵循展示、分区、卡片、正文、辅助五级语义刻度，用户名长文本仍可换行。
- 页面加载标志和开屏标志适度放大，不修改动画时序、路径、描边与减少动态行为。
- 底部中央添加按钮在全部皮肤及明暗模式下保持品牌青柠底色和深色前景，点击区不缩小。
- App 页面背景继续为纯色，拼图布局、贴纸几何、账号、数据和供应商配置不变。
