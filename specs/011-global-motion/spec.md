# Feature Specification: 全局高级动效系统

**Feature Branch**: `011-global-motion`

**Created**: 2026-08-23

**Status**: Approved

**Input**: 用户要求为所有 UI 增加不止弹跳的高级动效，例如气泡扩大，并保持苹果式克制质感。

## User Scenarios & Testing

### User Story 1 - 页面进入有空间层次 (Priority: P1)

用户切换主要页面时，背景光晕像气泡一样柔和扩散，内容按层级清晰显现，不再只是整体上下弹跳。

**Why this priority**: 页面切换是全站最频繁的动效触点，决定整体质感。

**Independent Test**: 依次切换首页、衣橱、添加、推荐、收藏和设置，观察每页都有一致但不抢内容的进入节奏。

**Acceptance Scenarios**:

1. **Given** 用户进入任一主要页面，**When** 页面内容出现，**Then** 背景扩散、内容显现和卡片层级按统一节奏完成。
2. **Given** 用户快速切换页面，**When** 动效尚未完全结束，**Then** 页面仍可立即交互且不会闪烁或错位。

---

### User Story 2 - 操作反馈细腻且可理解 (Priority: P1)

按钮、导航、卡片、输入框和状态提示通过填充扩散、光泽流动、轻微景深和状态形变反馈操作，不使用夸张弹跳。

**Why this priority**: 微交互直接影响产品是否显得精致和可靠。

**Independent Test**: 使用键盘、鼠标和触屏操作主要按钮、底部导航、衣物卡片及表单，确认每种控件都有合适反馈。

**Acceptance Scenarios**:

1. **Given** 用户悬停、聚焦或按下可交互控件，**When** 状态变化，**Then** 控件以颜色扩散、边缘高光或微小深度变化反馈。
2. **Given** 当前底部导航项改变，**When** 新页面激活，**Then** 选中背景以气泡式扩展形成，而非图标跳动。

---

### User Story 3 - 动效可降级且不影响性能 (Priority: P2)

偏好减少动态或减少透明度的用户获得稳定、清晰、无位移的界面；普通设备上动画保持顺滑且不阻塞操作。

**Why this priority**: 高级感必须建立在舒适、可访问和稳定之上。

**Independent Test**: 开启系统“减少动态效果”和“减少透明度”后重复核心路径，确认信息、焦点和操作结果完全保留。

**Acceptance Scenarios**:

1. **Given** 系统启用减少动态效果，**When** 浏览全站，**Then** 位移、缩放和持续动画被关闭，状态仍清楚。
2. **Given** 系统启用减少透明度，**When** 查看玻璃导航和悬浮控件，**Then** 使用不透明材质且对比度足够。

### Edge Cases

- 慢速设备或连续点击时，动画不得阻止导航、表单提交和错误提示。
- 页面含长列表时，只对可见区域和必要元素使用动画，避免每次滚动重复播放。
- 浏览器不支持部分现代视觉能力时，界面回退为普通颜色和淡入，不影响布局。
- 加载、成功、警告和错误状态不能仅依赖动效表达。
- 深色按钮的高光不得以高对比白条快速掠过，避免产生“一闪而过”的故障感。

## Requirements

### Functional Requirements

- **FR-001**: 系统 MUST 建立统一的动效时长、缓动、层级和延迟规则。
- **FR-002**: 所有主要页面 MUST 使用背景气泡扩散与内容显现组合，而非单一弹跳。
- **FR-003**: 底部导航当前项 MUST 使用扩展式选中背景，中央添加入口不得继续上下跳动。
- **FR-004**: 按钮、链接卡片、表单控件和状态卡 MUST 具有与用途一致的悬停、聚焦、按下或出现反馈。
- **FR-005**: 列表进入 MUST 使用克制的错峰显现，并限制总延迟，避免长列表等待。
- **FR-006**: 动效 MUST 优先使用不触发布局重排的属性，且不得阻挡指针或键盘操作。
- **FR-007**: 系统 MUST 完整支持减少动态效果和减少透明度偏好。
- **FR-008**: 动效不得改变现有视觉基线、业务行为、数据流或路由语义。
- **FR-009**: 深色主要按钮 MUST 使用稳定的颜色、按压或扩散反馈，不得自动播放高对比扫光。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 首页及五个主导航页面均呈现统一的空间进入效果和清晰当前导航状态。
- **SC-002**: 核心控件从操作到视觉反馈的目标延迟不超过 100ms，页面进入主体在 700ms 内稳定。
- **SC-003**: 390px 和桌面宽度下无动画引起的横向溢出、布局跳动或遮挡。
- **SC-004**: 减少动态效果下核心流程功能 100% 可用且无持续动画。
- **SC-005**: 浏览器验收无框架错误覆盖层和控制台错误。

## Assumptions

- 延续当前冷白银灰、近黑、系统蓝、软圆角和克制玻璃视觉，不引入新的动效依赖。
- 气泡扩散是全局标志性动效；其他控件采用更轻的填充、高光和景深反馈，避免全站同时运动。
