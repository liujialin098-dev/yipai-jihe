# UI Contract: 贴纸画板与月历

## View switch

- 顶部使用“画板 / 月历”双段控件，原生按钮并暴露选中状态。
- 切换视图不得清空当前选择、生成状态或画板布局。

## Canvas

- 4:5 无格子画板，允许任意贴纸重叠。
- 拖动 1:1 跟随指针；选中贴纸显示克制轮廓，不遮挡衣物主体。
- 提供大小滑杆、旋转滑杆、四向微调、置顶、置底和恢复排布。
- 底色提供丁香、青柠、晴空、珊瑚、冷白五种浅色，以及夜紫、午夜、深林、浓咖四种深色。
- 深色主题自动使用高对比标题和亮色选中轮廓；屏幕画板与导出图片必须复用同一组渐变色值。
- 布局控件只在已有选择时出现；空状态继续引导选衣物。

## Export

- 下载和分享为两个独立按钮。
- 仍有待生成衣物时禁用成品输出，并提供“先生成贴纸”的短反馈。
- 分享不支持时下载同一 PNG，不显示技术术语。

## Calendar

- 周一至周日七列，每个日期格保留一致比例。
- 有日记时显示代表衣物贴纸；多件衣物显示件数角标。
- 无日记日期留白，今天使用轮廓强调，未来日期不提供新增入口。
- 月份头部提供前后切换；不得进入超过当前月份的未来月份。
- 摘要显示记录天数、代表单品数和最常出现单品。

## Visual and accessibility

- 继续使用浅丁香主背景、冷白画板和四色点缀，不复制参考页面棕色或品牌。
- 主要触控区域至少 44px；拖动之外提供滑杆、方向按钮和键盘方向键。
- 所有独立图标按钮必须有可读名称和可见焦点。
- 减少动态时只保留颜色、轮廓和短透明度反馈。
