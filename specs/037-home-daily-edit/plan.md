# 实现计划

设计：浅紫背景 #f7f3fb、白色 #ffffff、墨色 #27222d、丁香 #d8cbea、青柠 #e5f69b；复用主题变量的日夜配对，不增加全局色板。标题沿用 ZCOOL，正文沿用系统中文与 Fredoka 数字；唯一视觉特色为原有衣物的松散排布，不新增装饰编号或广告语。

布局：顶部导航 → 标题/日期/精简天气 → 无格衣物排布或真实空状态 → 一项主操作 → 五日贴纸手帐 → 体验身份保存提示 → 底部导航。约两屏以内，主要内容不再重复套卡。

实现：保持 Server Component；复用 getRecommendationPageData 与 getDiaryMonthData（跨月时读取两个月），纯函数生成日期条与代表单品。天气组件增加 compact 展示，复用同一加载/过期/取消逻辑；不新增网络服务、依赖或数据写入。首页图像复用 GarmentSticker，普通照片保留原图纸卡，不能假装已抠图。

验收：固定日期跨月/跨年、收藏优先、缺图/已移除、3～7 件布局边界、未登录网关、过期天气展示；check/build、036/037 回归，真实本地窄屏和日夜截图、导航点击。
