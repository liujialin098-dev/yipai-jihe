# Quickstart: 全局衣物贴纸统一验收

## 前置条件

- 本地 `.env.local` 可以读取当前 Supabase 项目。
- 测试身份至少有一件透明图衣物、一件只有原图的衣物；缺图状态可用静态门禁覆盖。
- 不需要调用 AI、百度抠图或创建新测试数据。

## 自动检查

```powershell
npm run check
npm run build
npm run verify:sdd-032
```

预期：三个命令退出码均为 0；门禁确认五类入口复用共享组件、透明图参数完整、上传核对未被替换、无数据写入与退役功能恢复。

## 390px 浏览器验收

1. 登录有效体验身份，打开首页，确认最近衣物呈现纸贴或原图纸卡。
2. 进入衣橱详情，确认透明图优先、主图完整，编辑和收藏可用。
3. 打开日记，检查历史记录、手工选衣、常穿和未使用衣物的材质一致。
4. 打开收藏，确认单品和整套预览使用相同材质，取消收藏仍可操作。
5. 打开添加衣物页面，确认上传预览继续显示原始照片。
6. 核对所有页面 `scrollWidth` 不大于视口宽度，控制台无 error 或框架错误层。
7. 开启减少动态，确认没有贴纸位移或缩放；开启减少透明度，确认纸纹关闭但衣物仍清楚。

## 数据与安全复核

- 不执行迁移，不新增环境变量。
- 不修改图片路径、日记快照、收藏记录或 Storage 对象。
- 不请求专业去背，不重新开放自由画布、分享卡片或人物预览。
