# UI Contract: GarmentSticker

## 目的

统一衣橱和推荐场景中的衣物图片材质，保证透明图与原图使用不同且正确的展示逻辑。

## 输入

- `alt`: 必填，可理解的图片替代文本。
- `imageUrl`: 原图地址，可空。
- `cutoutUrl`: 透明底地址，可空。
- `sizes`: 响应式图片尺寸提示。
- `priority`: 是否优先加载，默认关闭。
- `className`: 外部布局尺寸与圆角扩展。
- `imageClassName`: 仅用于必要的图片适配，不得改变衣物颜色。

## 输出状态

1. `cutoutUrl` 存在：优先显示透明图，根节点标记 `data-sticker-mode="cutout"`。
2. 只有 `imageUrl`：显示原图纸卡，根节点标记 `data-sticker-mode="photo"`。
3. 两者都不存在：组件返回空，由调用方显示当前缺图状态。

## 视觉约束

- 白色轮廓位于真实衣物层后方，只允许在透明模式出现。
- 纸张纹理位于所有图片层下方，不得覆盖真实衣物像素。
- 阴影带冷紫色调，不使用纯黑、强发光或扫光。
- 悬停只允许轻微抬升和阴影变化；减少动态时必须取消位移和缩放。

## 交互约束

- 组件本身不拦截点击、键盘或触摸事件。
- 收藏按钮、角色标签、详情链接和换件按钮仍由调用方拥有。
- 不新增网络请求、上传、去背或图片修改操作。
