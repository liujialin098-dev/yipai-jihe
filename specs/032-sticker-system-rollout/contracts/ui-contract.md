# UI Contract: 全局衣物贴纸入口

## 入口范围

- 首页最近衣物预览。
- 单品详情主图。
- 日记记录卡和手工选衣。
- 利用率常穿与未使用衣物。
- 单品收藏和整套收藏预览。

## 输入合同

每个入口在当前衣物存在时向共享贴纸组件提供：可理解的 `alt`、`imageUrl`、`cutoutUrl`、对应布局的 `sizes` 和外部尺寸/圆角类名。

## 输出合同

1. 有透明图：根节点为 `cutout` 模式，显示透明衣物、白边、纸纹和紫调轻阴影。
2. 只有原图：根节点为 `photo` 模式，显示完整圆角纸卡。
3. 完全缺图：共享组件不输出内容，入口继续显示已有缺图或历史名称状态。

## 交互合同

- 贴纸层不接收指针事件，不阻挡父链接、选择控件、收藏按钮或遮罩。
- 日记选择勾、整套剩余数量和推荐角色标签必须保持在贴纸之上。
- 上传核对、编辑表单预览和已停用画布不属于本合同。

## 安全合同

- 不读取或输出 Storage 私有路径、用户标识和签名参数。
- 不发起额外 API、去背、上传或持久化请求。
- 不修改现有账号归属、RLS 或图片生命周期。
