# 验收与操作

1. 打开本地 `/stickers`，选择一件已有透明图的衣物，点击画板上的贴纸。
2. 点「裁切」，拖动上/右/下/左四个边柄。旋转后的衣物仍沿自身方向裁切；「精确调整」支持滑杆和方向键；「恢复完整」清零。完成后四角缩放/旋转恢复。点击画板空白取消选择。
3. 点「橡皮擦」，在放大衣物图上划动。擦除多余水印碎片；「恢复」仅还原本次进入前的透明图，撤销保留最近6笔；重置还原本次源图。笔刷8～64px，深浅预览底可切换。
4. 取消有修改时需确认；保存写入这件衣物的共享贴纸，但原照片不变。网络失败编辑保留；空白图不可保存；版本冲突需退出重新编辑。
5. 下载/分享沿用画板层级、裁切、底色和描边颜色。此阶段同步修正长条形图片在下载与预览的裁切坐标差异。
