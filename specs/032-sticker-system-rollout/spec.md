# Feature Specification: 全局衣物贴纸统一

**Feature Branch**: `master`

**Created**: 2026-09-07

**Status**: Ready

**Input**: User description: "继续贴纸。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 全应用看到一致的衣物贴纸 (Priority: P1)

用户从首页进入衣橱、单品详情、日记或收藏时，同一件衣物应保持一致的纸贴材质，不再在不同页面之间切换为突兀的普通矩形缩略图。

**Why this priority**: 贴纸已经成为衣橱与推荐的主要视觉语言，核心页面不一致会削弱品牌识别和完成度。

**Independent Test**: 选择一件已有透明图的衣物，依次打开首页、详情、日记选衣、日记记录、收藏和利用率，确认均显示相同的白边、纸纹与轻阴影。

**Acceptance Scenarios**:

1. **Given** 同一件衣物存在透明图，**When** 用户在不同核心页面查看它，**Then** 所有入口都优先显示透明衣物贴纸，款式、颜色和名称保持一致。
2. **Given** 页面同时显示多件衣物，**When** 用户滚动和点击，**Then** 贴纸阴影不被意外裁断，也不遮挡选择状态、收藏按钮或统计信息。
3. **Given** 用户进入衣物详情，**When** 查看大图，**Then** 大图保持完整并呈现更清晰的纸贴层次，编辑和收藏操作仍可使用。

---

### User Story 2 - 普通照片与缺图稳定降级 (Priority: P2)

当衣物没有透明图或图片缺失时，用户仍能在所有入口看到完整、可理解的内容，不会因为全局贴纸升级而丢失衣物或出现错误轮廓。

**Why this priority**: 当前数据同时包含透明图、普通原图和历史缺图状态，统一视觉必须覆盖真实混合数据。

**Independent Test**: 使用只有原图和完全缺图的衣物遍历同一组页面，确认原图纸卡与缺图提示都保持完整。

**Acceptance Scenarios**:

1. **Given** 衣物只有普通照片，**When** 用户在任一核心入口查看，**Then** 照片以圆角纸卡完整显示，不伪造衣物透明轮廓。
2. **Given** 衣物图片不可用，**When** 页面渲染该项目，**Then** 原有缺图图标、名称或“已移除”状态仍清楚可见。
3. **Given** 用户正在添加新衣物，**When** 核对上传内容，**Then** 页面继续显示原始上传照片，不应用贴纸装饰影响确认。

### Edge Cases

- 日记中的历史衣物已归档或删除时，快照名称必须保留，不能显示为破损图片。
- 大图、方形缩略图、横向统计行和双列卡片必须共享材质，但各自比例不能被强制改写。
- 透明图签名地址不可用时，页面必须继续使用可用原图；两者都不可用时由原入口降级。
- 选择勾选、数量遮罩和收藏按钮必须位于贴纸之上，并保持至少 44px 的可触达区域。
- 减少动态和减少透明度设置继续沿用现有降级，不新增循环动画或闪烁。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 首页衣橱预览 MUST 使用统一衣物贴纸展示规则。
- **FR-002**: 单品详情大图 MUST 优先使用已有透明图，并在不可用时展示完整原图纸卡。
- **FR-003**: 日记记录卡、手工选衣和利用率报告中的当前衣物 MUST 使用统一贴纸展示规则。
- **FR-004**: 单品收藏和整套收藏预览 MUST 使用统一贴纸展示规则。
- **FR-005**: 所有新接入入口 MUST 保留原有链接、选择、收藏、统计和缺图行为。
- **FR-006**: 上传确认、图片识别和历史退役画布 MUST NOT 因本阶段重新接入贴纸组件。
- **FR-007**: 系统 MUST 继续优先使用已有透明图，并在缺失时使用原图；不得触发新的去背请求。
- **FR-008**: 系统 MUST NOT 修改衣物图片、账号数据、数据库结构、Storage 对象或访问权限。
- **FR-009**: 贴纸在 320px 及以上视口 MUST 不造成水平溢出、文字遮挡或点击区域缩小。
- **FR-010**: 贴纸的悬停反馈 MUST 只在支持精确指针的设备启用，并在减少动态时取消位移与缩放。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 首页、详情、日记、收藏和利用率共五类核心入口中，100% 的可用透明图衣物使用统一贴纸材质。
- **SC-002**: 100% 的普通照片在新接入入口中保持完整纸卡降级，且不出现错误透明轮廓。
- **SC-003**: 390px 视口下所有新接入页面的 `scrollWidth` 不大于视口宽度，主要操作无遮挡。
- **SC-004**: 日记选择、单品收藏、衣物详情编辑和统计跳转四类原有操作的验收成功率保持 100%。
- **SC-005**: 本阶段不产生数据库迁移、图片写入或第三方去背请求。

## Assumptions

- SDD-031 的共享贴纸组件和材质是本阶段的唯一视觉基线。
- “继续贴纸”解释为将已确认的贴纸语言覆盖到仍显示衣物普通缩略图的核心入口。
- 添加衣物工作区必须保留原图核对职责，因此明确排除。
- 已停用的自由画布、分享卡片、专业抠图入口和人物预览继续保持停用。
