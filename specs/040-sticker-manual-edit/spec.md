# SDD-040 人工擦除与四边裁切

2026-09-08；范围：贴纸画板的既有透明衣物，不新增模型、公开素材、数据库表或部署。

- 用户选中贴纸后，可打开橡皮擦，在放大预览中擦除多余水印和背景碎片；恢复仅恢复本次进入编辑前的透明图，不带回原照片背景。支持调节笔刷、逐笔撤销、重置、取消和保存。
- 保存修改当前账号该单品的共享透明贴纸，原照片不变；未保存、失败或版本冲突不得覆盖现有结果。全透明结果不得保存。
- 裁切模式在贴纸上/右/下/左边提供可拖动控件，旋转后拖动仍符合局部方向；保留精确滑杆作为无需拖动的替代。四角缩放/旋转在普通模式显示，避免手机上八个控件冲突。
- 四边裁切是画板级非破坏操作，兼容原有v2布局、层级、下载与分享；橡皮擦是单品级保存，保存前明确告知。
- 手机触控区至少44px；画板无网格；空白点击取消选中；弹窗支持键盘关闭、焦点约束、加载/保存失败反馈。

验收：四方向与旋转固定样本；擦除/恢复/撤销/取消/保存；服务端所有权、输入上限、并发版本冲突、失败清理；质量检查和本地浏览器。真机/线上验证独立记录，不用模拟样本冒充。
