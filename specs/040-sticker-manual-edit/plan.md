# 实施方案

复用React、原生Canvas、native dialog、现有Supabase用户客户端及Sharp，不新增依赖。新贴纸专用refine接口，旧410抠图路由保持停用。

1. 纯函数计算屏幕位移经旋转逆变换后的四边裁切，保留0～40%边界。
2. 客户端透明图缩至最长1280px；有限6笔历史；圆形硬边笔刷插值，恢复仅复制初始透明像素。保存PNG，不重裁边，保持画板坐标。
3. GET当前用户活跃单品透明图，返回不透明版本哈希。POST仅同源、PNG、3MiB及1280²像素内；重新getUser、归属验证和版本比较。
4. 新UUID私有展示/工作图均成功后CAS更新cutout_path；失败删除本次新文件，保留旧图与原照片。旧版本保留供人工恢复，本期不新增版本历史UI。
5. 更新当前贴纸列表及路由缓存，描边按新透明图重算；回归裁切、导出、层级。
