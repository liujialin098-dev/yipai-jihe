# Research: 全局高级动效系统

## 视觉方向

- **Decision**: 标志动效为“衣橱气泡”：页面背后的系统蓝/银白径向光晕扩大并淡出，前景内容随后以轻微模糊消退和裁切显现。
- **Rationale**: 气泡扩张回应用户示例，同时保持苹果式克制，不与衣物图片争夺注意力。

## 微交互策略

- **Decision**: 导航使用扩展选中胶囊；按钮使用内层填充扩散和边缘光泽；卡片使用阴影/高光/微小景深；加载使用柔和扫光。
- **Rationale**: 不同控件用符合其语义的反馈，不再把所有状态统一成上下弹跳。

## 性能与降级

- **Decision**: 主要动画限制为 `opacity`、`transform`、伪元素和渐变位置；不监听滚动，不引入 JS 动画运行时。
- **Rationale**: 保持 Server Component 边界和移动端响应性。
- **Fallback**: 不支持特性时退化为淡入/颜色切换；`prefers-reduced-motion` 关闭位移、缩放、扫光和错峰。
