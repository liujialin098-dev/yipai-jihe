# Quickstart: SDD-015 独立验收

1. 运行 `npm run check`、`npm run build` 和 `npm run verify:sdd-015`。
2. 在 390px 依次打开首页、衣橱、添加衣物、推荐、收藏、设置、偏好和登录页。
3. 确认每页首屏只有一个明确主标题，元信息不再统一使用高亮蓝色眉题。
4. 确认首页计数和衣橱总数不使用装饰性前导零，标题没有异常紧缩或大面积占屏。
5. 确认添加页以“添加衣物”为标题，推荐结果的 AI 来源仍可见但不以高亮徽章抢占注意力。
6. 检查中文标题换行、正文行距、按钮文字和卡片标题，无截断、重叠和水平溢出。
7. 检查浏览器控制台无错误，并复核首页到推荐的核心操作没有行为变化。
