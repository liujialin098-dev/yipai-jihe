# 研究记录：精准搭配预览

## 决策 1：默认使用确定性原图分层板

- **结论**：采用固定人物比例参照 + 真实衣物原图卡片的确定性布局。
- **原因**：当前 28 件演示衣物中存在纯色背景和透明底混合素材，直接用 CSS 覆盖人物会遮挡背景或产生错误轮廓；原图卡片能 100% 保留颜色、款式、图案和配饰数量。
- **放弃方案**：继续使用通用文生图作为默认预览。它能生成氛围图，但会重绘衣物，无法满足“准确”。

## 决策 2：暂不接入专业 VTON API

- **结论**：本阶段不将用户衣物图片发送给第三方服务。
- **原因**：专业 VTON 需要处理人物图和衣物图，具有额外隐私、成本、失败重试和多层叠穿复杂度；先用本地确定性方案验证核心体验。
- **后续条件**：只有用户认可精准预览的信息价值后，才另建 SDD 评估专业 VTON。

## 决策 3：保留 AI 效果图作为增强

- **结论**：现有 GPT-image-2 效果图按钮保留，但不作为准确性主视图。
- **原因**：AI 图可提供视觉氛围，但必须与真实衣物原图并列，避免把生成结果当作衣物事实。
