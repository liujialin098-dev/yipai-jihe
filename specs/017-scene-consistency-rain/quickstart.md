# Quickstart: SDD-017 验收

## 目标

验证休闲、约会、正式场景不再串台，并验证真实雨天在库存完整时至少提供一套防水三件套。

## 自动门禁

```powershell
npm run check
npm run build
npm run verify:sdd-017
npm run verify:sdd-014
npm run verify:sdd-005
npm run verify:sdd-012
npm run verify:sdd-013
```

## 固定样本验收点

1. 休闲结果不含仅约会、仅正式或仅通勤单品。
2. 约会结果不含仅休闲单品。
3. 正式结果不含仅休闲或仅通勤单品。
4. 同时标记当前场景与其他场景的基础款仍可通过。
5. AI 形态的伪造结果只要混入异场景单品，就被统一复验拒绝。
6. 雨、阵雨和雷雨被识别为雨天；雪天不被误判。
7. 完整且合法的冲锋衣、防水下装、防水鞋存在时，至少一套使用三件套。
8. 缺任一角色时仍输出普通合法搭配，不伪造、不重复。

## 浏览器抽验

在 390px 视口登录测试账号：

1. 用混合场景衣橱依次生成休闲、约会、正式推荐，检查每件衣物的场景归属。
2. 将城市目标日切到真实雨天时，检查防水单品只在衣橱存在时出现。
3. 确认页面没有新增横向溢出、控制台 error 或额外等待步骤。
