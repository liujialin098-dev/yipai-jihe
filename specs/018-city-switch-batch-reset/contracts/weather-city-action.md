# Contract: 推荐页天气城市保存

## 输入

- `city`: 去除首尾空格后的中国城市名称，2～40 个可见字符。
- 用户 ID 不从客户端接收，由服务端当前会话确定。

## 服务端流程

1. 验证当前会话。
2. 验证城市输入长度。
3. 使用既有城市解析服务得到规范城市名、行政区、经纬度和时区。
4. 只更新当前用户 `user_preferences` 的天气城市五元组与更新时间。
5. 删除当前用户全部旧推荐批次。
6. 刷新推荐、设置与偏好页面。

## 返回状态

```text
status: idle | success | error
message: string
city?: string
admin1?: string
```

## 用户反馈

- 成功：`天气城市已切换为上海，请重新生成搭配。`
- 输入非法：`请输入完整城市名，例如上海。`
- 无匹配：`没有找到这个中国城市，请检查名称后重试。`
- 解析不可用：`城市暂时无法确认，请稍后重试。`
- 会话失效：`当前登录已失效，请重新进入应用。`
- 保存失败：`天气城市暂时无法保存。`

任何错误都不得覆盖账号原城市或保留旧城市推荐作为当前结果。
