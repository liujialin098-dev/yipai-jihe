# SDD-039：八件首页拼图与实心彩色描边

- 首页有无推荐都展示最多8件不同的当前账号就绪贴纸，数量不足不复制或补造。主视觉标为衣橱拼图，与下方真实推荐标题/入口区分，不扩充推荐本身。
- 透明衣物描边默认纯白，可切换白/丁香/青柠/珊瑚/天蓝/墨色。本机统一偏好，首页和贴纸画板均有入口，其他贴纸展示同步；不修改照片/数据库。
- 移除放大副本和模糊投影。以真实透明通道生成圆盘膨胀实心轮廓，去掉半透明底影；抗锯齿只发生在最终轮廓边缘，不制造大面积虚影。
- 预览与画板PNG导出复用同一轮廓算法及颜色。旧原图纸卡继续降级，不把普通照片假装成已抠图。
- 图片处理失败时保留真实原图/透明衣物，不回退旧模糊描边。缓存有上限、无需重新付费抠图；不新增供应商或系统权限。
- 验收：8件/不足/重复/有推荐、像素实心与圆角、颜色与持久化降级、导出、移动日夜视觉。未要求部署，本阶段仅本地。
