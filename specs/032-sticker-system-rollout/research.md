# Research: 全局衣物贴纸统一

## 决策 1：继续复用单一贴纸组件

- **Decision**: 所有新入口直接复用 SDD-031 的 `GarmentSticker`。
- **Rationale**: 白边、阴影、纸纹和原图降级已经通过独立验收，复用可以避免页面间参数漂移。
- **Alternatives considered**: 每个页面单独写滤镜；生成新的贴纸图片。前者会产生视觉分叉，后者会增加写入和版本管理。

## 决策 2：只统一当前衣物，不伪造历史图片

- **Decision**: 日记和收藏只有在当前衣物仍可读取时显示贴纸；已移除项目继续展示历史名称占位。
- **Rationale**: 日记快照没有长期图片副本，凭名称伪造图像会误导用户。
- **Alternatives considered**: 把签名地址写入快照；用类别占位图替代。前者不持久有效且可能泄露地址，后者不能代表真实衣物。

## 决策 3：上传确认继续显示原图

- **Decision**: 添加衣物和识别确认页面不接入贴纸。
- **Rationale**: 该页面的目标是核对用户上传的真实照片和识别结果，装饰性处理会降低可判断性。
- **Alternatives considered**: 全应用无差别替换。虽然表面一致，但会损害核心确认任务。

## 决策 4：采用克制的纸张而非混乱拼贴

- **Decision**: 延续浅色纸张、低对比纹理和微弱不规则感，不引入随机抖动、霓虹或持续动画。
- **Rationale**: UI UX Pro Max 的纸张风格适合低成本纹理，Emil Design Engineering 强调高频交互应减少动画；这与当前高级、轻快的时尚基线一致。
- **Alternatives considered**: Gen-Z 极繁贴纸墙；拖拽拼贴。前者会破坏信息层级，后者属于已退役画布能力。

## 决策 5：保留原比例和覆盖层职责

- **Decision**: 页面继续决定方形、4:5 或横向尺寸，并把选择、收藏、角色与数量遮罩放在贴纸上方。
- **Rationale**: 贴纸只负责图片材质，避免承担业务交互后变成复杂组件。
- **Alternatives considered**: 在贴纸组件内部管理徽标和按钮。会造成过度抽象并增加不同页面的条件分支。
