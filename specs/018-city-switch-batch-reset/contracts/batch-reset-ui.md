# Contract: 满批连续入库界面

## 触发条件

- 当前队列长度为 10。
- 10 项状态全部为 `confirmed`。
- 当前没有进行中的上传、识别或确认操作。

## 用户操作

- 主按钮：`继续添加衣服`。
- 辅助入口：`查看衣橱`。

## 操作结果

1. 释放当前批次每一项的浏览器图片预览地址。
2. 将当前队列设为空。
3. 清除本批完成提示并重新显示可用的图片选择区。
4. 已入库衣物、入库记录和私有原图保持不变。

## 不允许的行为

- 不在有失败、待确认或处理中项目时显示满批重置。
- 不调用删除入库记录或 Storage 对象的接口。
- 不自动开始下一次识别。
