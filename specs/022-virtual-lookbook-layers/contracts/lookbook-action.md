# 契约：单套 Lookbook 生成 Action

## 输入

- `recommendationId`：推荐 UUID。
- `slot`：`1 | 2 | 3`。

浏览器不得提交用户 ID、衣物详情、Storage 路径、天气或提示词；服务端必须从当前会话和推荐记录重新读取。

## 返回

```text
status: idle | success | error
message: 面向用户的中文结果
```

成功时当前页面在同一 Server Action 响应中重新读取并显示签名图片。错误时只返回说明，不改变原推荐。

## 错误语义

- 输入无效：`这套搭配已经变化，请刷新后重试。`
- 会话失效：`当前登录已失效，请重新进入应用。`
- 未配置：`虚拟模特效果图暂未配置，真实衣物搭配仍可正常使用。`
- 限流：`效果图请求较多，请稍后重试。`
- 超时/供应商错误：`效果图暂时无法生成，请稍后重试。`
- 保存失败：`效果图已经生成，但暂时无法保存，请重试。`

## 安全约束

- 使用 `auth.getUser()` 派生用户身份。
- 推荐查询和更新同时约束 `id` 与 `user_id`。
- 图片路径由服务端构造，第一段固定为当前用户 ID。
- 返回值不得包含密钥、原始 base64、私有对象路径或供应商错误正文。
