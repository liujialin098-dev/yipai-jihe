# Feature Specification: 自然化文字排版

**Feature Branch**: `015-natural-typography`

**Created**: 2026-08-26

**Status**: Complete

**Input**: 用户希望全站文字排版减少 AI 模板感，同时保持现有苹果式视觉和业务功能。

## User Scenarios & Testing

### User Story 1 - 一眼看懂页面用途 (Priority: P1)

用户进入首页、衣橱、推荐、收藏、设置和登录等页面时，先看到简洁的功能标题和必要说明，不再被重复的小标题、宣传句和超大字干扰。

**Independent Test**: 依次打开核心页面，只读首屏文字即可准确判断页面用途与下一步操作。

**Acceptance Scenarios**:

1. **Given** 用户进入核心页面，**When** 查看首屏，**Then** 页面只保留一个主标题，元信息退居次要层级。
2. **Given** 页面需要解释功能，**When** 展示说明，**Then** 使用直接、具体的短句，不使用刻意的比喻或宣传口吻。

---

### User Story 2 - 全站层级稳定自然 (Priority: P1)

用户在不同页面之间切换时，主标题、章节标题、卡片标题、正文和元信息具有一致的尺寸、字重和间距。

**Independent Test**: 对比核心页面的标题和正文，确认同一语义层级不再使用多组接近但不同的字号和字距。

**Acceptance Scenarios**:

1. **Given** 两个页面都使用一级标题，**When** 对比视觉，**Then** 字号、字重、行高和字距遵循同一 token。
2. **Given** 标题在窄屏换行，**When** 宽度为 390px 或更小，**Then** 换行自然且没有截断或横向溢出。

---

### User Story 3 - AI 能力透明但不抢主角 (Priority: P2)

用户仍能知道推荐或识别来自 AI，但 AI 标签只作为必要来源信息，不再成为页面的视觉主题。

**Independent Test**: 查看添加衣物和推荐页，确认功能标题以用户任务命名，同时结果来源仍可辨认。

**Acceptance Scenarios**:

1. **Given** 推荐已生成，**When** 查看天气信息，**Then** 可以看到 AI 或基础生成来源，但来源不使用高亮徽章抢占注意力。
2. **Given** 用户添加衣物，**When** 查看首屏，**Then** 标题描述“添加衣物”，说明识别和人工核对流程，不使用 AI 作为主标题。

## Requirements

### Functional Requirements

- **FR-001**: 系统 MUST 建立页面元信息、页面标题、页面说明、章节标题、卡片标题和展示数字的统一排版 token。
- **FR-002**: 核心页面 MUST 去除重复的蓝色眉题、过度紧缩字距、超大数字和装饰性前导零。
- **FR-003**: 核心文案 MUST 优先说明页面用途、当前状态和下一步操作，避免刻意比喻、空泛鼓励和宣传句。
- **FR-004**: AI 来源 MUST 保持可见，但不得作为所有相关页面的主标题或高对比视觉标签。
- **FR-005**: 本阶段 MUST 保留现有路由、业务行为、表单字段、数据结构、动效和品牌视觉 token。
- **FR-006**: 标题和正文 MUST 在 390px 移动端自然换行且无水平溢出。
- **FR-007**: 系统 MUST 提供静态门禁，防止核心页面恢复旧超大标题、前导零计数和已移除的模板式文案。

## Success Criteria

- **SC-001**: 8 个核心页面全部接入统一页面标题层级。
- **SC-002**: 核心页面不再出现 3.25rem 页面标题、4.8rem 计数、0.075em 以上负字距或两位前导零计数。
- **SC-003**: 首页、衣橱、添加、推荐、收藏、设置、偏好和登录首屏文案均通过人工自然语言复核。
- **SC-004**: `npm run check`、`npm run build` 与 `npm run verify:sdd-015` 通过。
- **SC-005**: 390px 核心页面无水平溢出、标题截断或控制台错误。

## Assumptions

- 保留系统字体栈，不新增网络字体或依赖，避免中文字体加载和布局偏移。
- 本次属于保留式视觉演进，不改变导航、信息架构和表单流程。
- 继续使用现有冷白银灰、近黑、系统蓝、软圆角和 Web 玻璃近似材质。
