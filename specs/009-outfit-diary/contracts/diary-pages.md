# Contract: 穿搭日记页面

## `/diary`

### 查询参数

- `view=diary|report`，默认 `diary`。
- `month=YYYY-MM`，仅日记视图使用，默认账号城市时区下当前月；未来月份回退当前月。
- `range=30|90|all`，仅报告视图使用，默认 `30`。

### 日记视图

- 页面标题、月份前后切换、本月记录天数。
- “手工记录”主入口与“查看收藏”次入口。
- 每条卡片展示日期、标题、场合、来源、1～8 件衣物、短记、编辑与删除。
- 当前衣物仍存在时显示私有/演示图片；不存在时显示快照名称。

### 报告视图

- 30 天、90 天、全部三个胶囊切换。
- 总利用率、记录天数、穿着单品次数。
- 最常穿列表：次数、最近日期、利用状态。
- 未穿列表：当前可见日常衣物，链接到详情。
- 无记录时显示真实 0 值和开始记录入口。

## `/diary/new`

### 查询参数

- `date=YYYY-MM-DD`：可选；默认今天，用于编辑已有日期。

### 页面行为

- Server Component 读取当前日期已有记录和当前可选衣物。
- Client Component 管理日期、标题、场合、短记和多选状态。
- 选择计数实时显示；达到 8 件后未选项不可继续选择。
- 保存成功后提供返回日记入口；失败保留选择。

## 推荐卡接入

- 今日推荐每套显示“记为今日穿搭”。
- 明日推荐不显示可写按钮，改为“穿过后可记录”的静态说明。
- 成功反馈附带前往 `/diary` 的入口。
