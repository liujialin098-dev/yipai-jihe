# Data Model: SDD-041 品牌开屏与加载动效

本阶段无数据库实体、服务器状态或持久化字段。仅定义展示期 UI 状态：

## BrandMotionPresentation

- `variant`: `loader | splash`，决定循环加载或一次性开屏编排。
- `label`: 页面级等待时显示和朗读的短文案；开屏使用固定双语品牌名。
- `visible`: 由组件在页面树中的存在决定；不写入本地或账号存储。
- `motionPreference`: 由用户系统设置派生为标准或减少动态，不作为账号数据保存。
- `colorMode`: 继承应用当前浅色/深色主题；图标像素颜色始终保持不变。

## 状态转换

```text
完整打开：静态起始 → 图标合拢 → 字标出现 → 覆盖层淡出
页面等待：延迟隐藏 → 循环加载可见 → 页面完成后直接卸载
减少动态：静态品牌 → 短淡变 → 退出/卸载
```

## 不变量

- 动效状态不得改变页面业务状态或导航目标。
- 退出后的覆盖层不得继续接收点击或占据布局空间。
- 站内导航不重新挂载根开屏；完整刷新可重新开始。
